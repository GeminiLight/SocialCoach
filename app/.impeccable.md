## Design Context

### Users
20–35 岁的学生与职场早期人群，在手机上、通常是晚上或某场重要对话前夕（明天要谈加薪、要拒绝朋友、要和伴侣摊牌）打开应用。他们带着一点紧张与自我怀疑，想在安全的地方先练一遍，并得到一个懂行、不敷衍的教练反馈。使用时段短（3–5 分钟一轮），单手操作，环境安静。

### Brand Personality
三个词：**温暖、坦率、沉稳**（warm, candid, steady）。
像一位读过很多沟通学书籍、见过很多真实冲突的资深教练：不哄你，也不吓你；指出问题时给出证据（你说的原话），给建议时给出出处（哪本书、哪个理论）。情绪目标：进入时安心，练习中有一点真实压力，复盘后有被看见的感觉与明确的下一步。

### Aesthetic Direction
「温暖纸面 · 柔和层次」：以留白和低幅光影承托内容，保留教练的证据批注。普通分区不靠大量横线，避免表格感。
- 主题：浅色与深色。浅色以温暖米白为底；深色不是通用的发光暗色，而是「暗处的同一张纸」——深暖褐底、暖白墨、同一个赭石提亮后继续用。大面积强对比面（排练卡、下一步）在深色下不翻成白块，走 --slab。
- 深色跟随系统，设置里可显式覆盖（跟随系统 / 浅 / 深）。
- 颜色 / 字体：以 `src/app/globals.css` 与 `src/app/layout.tsx` 为唯一来源；主操作为墨色，低饱和赭石只用于批注，CASEL 保留能力色。组件使用 `.display` / `.num` / `.eyebrow`，不钉死字体名。
- 反参考：不做紫蓝渐变、不做玻璃拟态、不做左侧色条卡片、不做同尺寸图标卡片阵列、不做渐变文字。
- 记忆点：对话练习中的「目标进度」用纸面上逐格填墨的方式呈现；复盘报告像一页带批注的稿纸，引用你的原话并画线；能力成长用五边形雷达在纸上「晕开」。

### Design Principles
1. **证据先于评价**：任何反馈先引用用户原话，再给判断与出处。
2. **一次只做一件事**：每屏一个主动作，主按钮永远只有一个。
3. **等待要有内容**：所有 LLM 等待展示阶段化进度与教练正在做什么，不用空转圈。
4. **手感真实**：按压有形变、选中面连续移动、展开与正文切换有来由；只动 transform/opacity，缓动用 ease-out/expo，100–260ms。减少动效时改用静态表面，禁止弹跳。
5. **克制的装饰**：普通层级使用留白与柔和表面，线条保留给证据、进度和图形；不为每个区域添加边框或分隔线。
