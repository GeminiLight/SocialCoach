# NPC 与系统精修核验（2026-10-06）

本轮针对 NPC 的口吻、前文与情绪连续性、场景输入和听者动作做了本地修订。没有改模型、评分、用户资料存储或生产环境；尚未发布。

## 主要结果

- 文字和 3D 共用人物表演方向，保留阻力；15 位 3D 人物有双语口吻，新局冻结在私有方向里，旧档兼容；补齐私有快照的人物唯一性，避免遗漏人物进入复盘。
- 模型收到最近已记录的三人反应；不同场景只接收相关专属约束，保留完整转录与动作证据。
- 整句长台词复播、无依据“分钟已过”、未提供的“王姨”、未请求的“我Know”进入原有一次未展示修复。短应答、明确复述和已有来源仍有退路。
- 骨骼听者的点头实际生效，和程序人物共用一次有限弧线，减少动效、暂停及现场动作保持优先。

## 证据

| 记录 | 范围与结果 |
|---|---|
| `baseline.json` | 固定 10 个原始合成输入，glm-5.3-flash；格式完成 10/10，人工发现虚构乔宁的交接消息、未核对却声称扫过记录、发言时间凭空耗尽 |
| `candidate.json` | 同 10 个输入、同模型，完成 10/10；前两类典型串场 / 时间问题未重现；仍发现额外“看过合照”的修饰，随后收紧资料回答 |
| `school-final.json` | 同一个未知记录问题再测 3 次，均明确未核对并只提出未来核对，不再附加看过照片 / 扫过记录的经历 |
| `family-first.txt` / `family-final.json` | 各连续 12 回合，含玩笑、拒绝、转述、修复与续聊；运行契约通过，但人工发现称谓“王姨”和混写“我Know”，分别补狭义检查，不把格式通过当作完整语义通过 |
| `final.json` | 最终固定对照 9/10 首轮完成；一条英文文字流被原有保护判为中断，已显示内容未改写、未当作完整回合返回。该记录的 `text-9` 是英文文字输入 |
| `text-retry.json` | 同英文输入单独重试成功，记录完整模型 JSON 与可见协议；逐字符回放检查该次输出前缀一致。原失败未采到模型原文，不能声称已定位其原因；评估脚本现会保留合成失败原文 / 可见片段 |
| `browser.json`、`desktop.png`、`mobile.png` | 正式构建的桌面与 390×844 视口，合成旧对话续接、提交、5 条记录保存、3 人口吻快照、刷新 / 减少动效；无页面异常。生成与统计被拦截，真实模型验收另行运行 |
| `check.txt` / `build.txt` | 最终源码的 lint、类型、22 项核心测试、242 项 3D 回归与正式构建通过，执行结果见日志 |

首次网页探针用错了模拟接口路径，实际本地请求被预算配置保护拒绝，草稿和旧对话保留；改为 `/api/dinner/direct` 后完成提交与刷新。没有用该次拒绝伪装成模型验收。

## 判断与限制

人物现在可以用各自口吻接同一句话，记忆输入也更完整。部分对照里母亲的回应从直接追问转为保留关心与委屈，大姨仍在争取体面，父亲不替全家答应；没有把“更有人味”做成更容易哄。

这些是固定、非盲的小样本，时序不同，不能估计总体质量或稳定延迟，也不能证明任意 NPC 都像真人。事实与情绪的广泛语义、英文流式偶发中断、真实手机和人物音色仍需扩大验证。狭义校验覆盖已复现的问题，不替代通用语义核对。
