全部为开发者构造的虚构办公室对话和隔离浏览器档案，无真实用户记录、秘密配置或论文材料。

- `quality.json`：最终本地检查摘要，116 核心＋256 3D；正式构建 / 类型 / lint 通过。
- `browser/`：最终界面 8 组语言 / 主题 / 视口组合＋1 组异常恢复；模型与统计请求被拦截，不当作真实模型体验。
- `model/baseline`、`refined`、`clock-recheck`、`authority-recheck`、`flash-final`：快速模型的中间结果，含语义失败和一份第三轮格式失败。接口完成不等于事实正确。
- `model/smart`：最终 smart 档位六例，11 个真实 NPC 回合；中文回顾首次失败原件保留。
- `model/review-retry`：只对相同中文转录重试回顾，未重新生成角色台词，成功。
