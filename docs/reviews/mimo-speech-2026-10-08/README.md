# MiMo NPC 语音实测 — 2026-10-08

用户要求尝试 TokenDance 的 `mimo-v2.5-tts`，如果 NPC 声音更正常则采用。当前 NPC 音频来自浏览器 SpeechSynthesis。MiMo 是语音合成模型，不能替代现有强／弱文字模型；正文仍应来自原 NPC 台词。

用独立 Vercel 部署、安全复用同一网关的线上凭证，真实生成了三份 24 kHz、16 位、单声道 WAV。正式入口和 NPC 声音没有替换，密钥不读取回本地、不记录进原件；无用户真实语音、无克隆、无文本优化。

| 样例 | 音频时长 | 客户端首响应 | 完整下载 |
|---|---:|---:|---:|
| 白桦男声，非流式 | 6.24 秒 | 5.86 秒 | 6.54 秒 |
| 茉莉女声，非流式 | 8.48 秒 | 6.43 秒 | 7.23 秒 |
| 白桦男声，提供商流式 | 4.16 秒 | 3.60 秒 | 4.29 秒 |

流式场次记录到真实首个音频事件 1,346 ms、总提供商处理 2,090 ms、13 个 PCM 音频块。当前测试端点在服务端收集完整 PCM 后封装 WAV，尚不是客户端边生成边播放；不能把 1.35 秒写成当前页面的出声时间。三次合成的音频时长与语速不同，工具无法直接听取音频，因此没有据此宣称音质胜过当前设备音色，也未验证实际朗读是否逐字一致。已向用户提供样例并请求试听反馈。

5 项针对性检查覆盖凭证不跨服务商发送、assistant 原文载荷、音色白名单、响应大小、非音频拒绝、碎片 SSE 与 PCM 顺序。初版完整 33 核心／249 3D 检查通过，流式扩展 lint、类型、生产构建与针对性检查通过。界面和原有朗读流程未改。

后续采用条件：用户确认音色改善；客户端流式播放与取消／切场／隐藏／收音、暂停和晚到回调验证完成；保持原话、角色一致及私有模型的数据边界。当前此接入未完成，不能标为已上线 NPC 自然语音。
