# MiMo NPC 语音实测 — 2026-10-08

用户要求尝试 TokenDance 的 `mimo-v2.5-tts`，如果 NPC 声音更正常则采用。初轮验证时 NPC 音频来自浏览器 SpeechSynthesis。MiMo 是语音合成模型，不能替代现有强／弱文字模型；正文仍应来自原 NPC 台词。
