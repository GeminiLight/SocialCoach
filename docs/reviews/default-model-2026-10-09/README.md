## 实际结果

- 提供商模型列表与实际 JSON 生成通过。
- 主站实际文字回复约 3 秒、3D 回复约 9 秒，完整协议与人物回复可读取；原件为 [文字](./vercel-roleplay.json)、[3D](./vercel-dinner.json)。
- 国内公开嵌入页已完成文字对练；检查临时不可用后通过重新检查恢复，模型连接错误没有被隐藏。
- 复盘初测失败：内部原话校验正常结束，却返回空正文。相同调用链的诊断确认默认 5,000 token 校验被推理占用。
- 第一版修订关闭有限输出校验 / 字段修订的额外推理；本地有通过样本，但主站复测仍在两次修订后被语义核验拒绝，不能据此宣布复盘稳定。摘要见 [首次兼容性对照](./debrief-compatibility.json)。
- 最终方案保留 DeepSeek 复杂原话核验的低强度推理，将该步骤输出预算调至 10,000，留出最终 JSON；短字段修订继续关闭推理。原话 / 事实检查、最多两次语义修订和 165 秒 / 8 次调用上限保留。同一转录的真实完整报告与核验约 63 秒通过，核验没有要求进一步修订；摘要见 [推理核验对照](./reasoned-check.json)。
- 三项反例回归先失败后通过；正式检查与最终线上复盘另在发布时复核。NPC 语音独立凭证的真实 PCM 请求为 HTTP 200，99,840 bytes。
