# DeepSeek 默认模型切换与复盘兼容验收

2026-10-09，按用户要求将 Vercel / ModelScope 的默认共享模型改为 OpenAI 协议、`https://api.deepseek.com`、fast / smart 均为 `deepseek-flash`。密钥写入平台 Secret；没有写入代码、文档或测试原件。共享中央日上限仍为 100,000,000，计数与并发政策保留。自然语音单独配置原 MiMo 网关凭证，保留已有声音。

## 实际结果

- 提供商模型列表与实际 JSON 生成通过。
- 主站实际文字回复约 3 秒、3D 回复约 9 秒，完整协议与人物回复可读取；原件为 [文字](./vercel-roleplay.json)、[3D](./vercel-dinner.json)。
- 国内公开嵌入页已完成文字对练；检查临时不可用后通过重新检查恢复，模型连接错误没有被隐藏。
- 复盘初测失败：内部原话校验正常结束，却返回空正文。相同调用链的诊断确认默认 5,000 token 校验被推理占用。
- 候选修订只关闭有限输出校验 / 字段修订的额外推理，保留完整报告推理、原话 / 事实检查、最多两次语义修订与总调用上限。真实同一转录完成检查、两次字段修订与最终认可；没有绕过不合格报告。摘要见 [兼容性对照](./debrief-compatibility.json)。
- 两项回归先失败后通过；完整检查为 65 项核心与 255 项 3D 测试，正式构建通过。公开服务器完整复盘在补丁发布后复核。

以上是少量真实请求与模拟设备浏览器验收，不是模型盲测或长期成功率。
