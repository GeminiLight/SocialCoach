# 首页入口优先级 — 2026-10-08

用户明确要求首页优先推荐每日练习，真实对话排练保留为次要选择。此前无当日场景时，真实对话排练被放到推荐区域上方，并升级为高亮主卡片；每日推荐反而以「也可以」开头、使用次按钮。

现在首页先显示每日推荐区域：没有当日推荐时，提供突出且清晰的「推荐今日练习」主按钮；生成后展示原有场景卡片。真实对话排练始终只出现一次，位于推荐之后，使用更小的标题、简短说明与普通链接，不再展示步骤列表或高亮按钮。页首说明也改为每日练习的轻量邀请。未完成练习保留继续入口，并避免同时出现两处同一场景邀请。

四种浏览器组合通过：中文手机浅色、英文手机深色、中文桌面深色、英文桌面浅色。区域顺序、按钮优先级、横向溢出、推荐生成与保存、刷新后保留、排练跳转及未完成练习入口均验证。局部 axe 没有确认违规；主按钮对比度补充按实际渲染颜色计算，均达到 4.5:1。主题切换动画须稳定后检查，部分自动检查的不确定项保留在原件中。见 [verification.json](./verification.json)。

lint、类型检查及生产构建通过。本轮没有修改推荐算法、API、模型、预算、记录格式或自动生成时机；浏览器流程用受控响应验证，没有计费推理。发布记录在 [release.json](./release.json)。
