# SocialCoach — 产品定义

> 参考论文：Wang et al., *SocialCoach: Personalized Social Skill Learning with Agentic Tutoring and Practice* (arXiv 2606.04155v2)。

## 一句话
**把生活里最难开口的那场对话，先在这里练一遍。** 和 AI 角色实战演练，拿到有理论依据的教练复盘，每天 3 分钟。

## 目标用户与日活逻辑
- 20–35 岁学生与职场早期人群（论文用户研究人群）。
- 日活钩子：① 每日一练（自适应排程，3–5 分钟）② 「排练真实对话」：把明天要谈的加薪 / 分手 / 拒绝请求 先演一遍 ③ 连续打卡 + 能力雷达可见成长 ④ 复盘报告可分享。

## 论文框架 → 产品功能映射
| 论文模块 | 产品实现 |
|---|---|
| 理论→案例→场景 三层知识库 | `src/data/corpus/`：可追溯来源的策略理论、案例、练习场景（中英双语） |
| CASEL 5 能力 × 34 技能 × 7 情境标签 | `src/data/taxonomy.ts`，用于筛选、检索、雷达图 |
| 用户画像 U、目标 G、熟练度 U_p、历史 H | 本地持久化 store（零注册门槛，随时导出） |
| 处方 → 检索 → 适配 排程 | `/api/schedule`：LLM 处方 JSON → 标签过滤 + 语义打分检索（约束按固定顺序放松，核心约束不放松）→ 角色适配 |
| 目标驱动沉浸式模拟 | `/api/roleplay` 流式 NPC 对话，目标进度、回合上限、成功/失败判定，角色一致性 prompt |
| 行为诊断 + 缺陷归因（acquisition / performance） | `/api/assess`：证据引用转录片段，映射到 CASEL 与目标技能 |
| 知识检索 + 苏格拉底式反思 | 报告内嵌理论/案例卡片，反思问题可作答并获教练回应 |
| 期望熟练度增量估计（有界、非负） | 报告后可见的能力增长动画；明确标注为“估计” |

## 页面
- `/onboarding` 60 秒：选 3–5 个目标技能 → 常见情境 → 一句话自我介绍
- `/` 首页：今日练习卡（含“为什么推荐给你”）、连续天数、能力雷达、排练真实对话入口
- `/arena` 练习场：按情境 / 技能 / 难度筛选的全部场景
- `/practice/[id]` 简报 → 对话 → 复盘报告（单路由多阶段）
- `/rehearse` 描述真实处境 → 生成专属场景
- `/progress` 成长：雷达、各技能熟练度、时间线、反思日志
- `/learn` 知识库：理论与案例，可收藏
- `/settings` 语言、模型、数据导出 / 重置

## 设计原则
- 移动优先（≤480px 内容宽度，桌面居中）、底部 Tab。
- 「温暖纸面」视觉：米白底、墨色字、赭石强调、深青辅助；无泛用紫色渐变。
- 每个等待都有意义：复盘生成时展示阶段化进度（诊断 → 归因 → 检索 → 生成）。
- 所有 LLM 输出对用户语言自适应（zh / en）。
- 安全声明：低风险练习与反思，非临床评估。
