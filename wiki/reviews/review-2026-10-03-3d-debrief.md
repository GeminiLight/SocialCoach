# 3D 与文字共用复盘验收

主站 `/3d` 将真实发言导入现有 Session，进入同一报告、知识、反思、复盘咨询、能力记录与本地历史。现场入口缩为最后一次原话和真实回应；报告保持纸面阅读，公开现场观察另列。实现见 [方案](../archive/specs/spec-3d-debrief.md)。独立演示仓库不参与本次交付。

## 已完成的检查

- 154 项 3D 检查通过：十开局 × 双语转换、原始记录不被修改、旧档案、公开背景出处、NPC 主句 / 插话顺序与去重、未发送草稿 / 镜头 / 私有设定隔离、原话与观察 ID 校验、错回合 / 重复 ID / 未来动作拒绝，以及原共享评估与咨询任务。
- 同局能力变化先核对新增发言引文，再扣除已经计入的技能增量；三份连续快照、新局、旧记录和文字练习均检查。实际 Zustand applyReport 重复执行不重复加分；持久化快照保留报告 / 观察 / 实际新增值，日期不重复。
- 原复盘助手 23 项合同检查通过；类型、相关静态检查和生产构建通过。2D 未附 sceneContext 时保留原报告形状与评分。
- 家庭隐私中文、办公室分工英文，各三轮真实模型检查：引文、知识来源与观察对应可验证，报告与咨询成功返回。规则补充未回答的下一回合不能算过去的弱点，改写不使用后来才发生的回复，不要求额外承诺换取礼貌。

## 浏览器路径

本地最终生产预览 `http://127.0.0.1:4357/3d`，桌面及 390 × 844 手机宽度。

- 无档案访客直接开始；零次开口不能生成评价。用茶回应、指定陈总和真实发言进入报告；未发草稿没有出现在转录或评价中。
- 原话 → 知识 / 反思 / 复盘助手路径完整。咨询明确举茶杯不等于喝酒同意、走近不等于私聊；刷新后问答保留。
- 返回保持现场、对象和草稿，提前结束仍为 1/12；继续不会变成 1/18。同一段重新打开复用原报告与问答，不重新评价。第二次成功发言后按钮回到“生成”，创建独立报告，旧报告保留。
- 一次续聊请求超时后保留草稿与 1/12，没有把失败输入写进转录；重试成功后为 2/12，包含实际 NPC 主句与小周插话。
- 重练从同场同开局 0/12 开始，显式清除当前局草稿；旧主站报告仍能打开。英文办公室入口、回应及报告检查与本局 ID 更新一起完成。
- 手机报告横向尺寸为 390/390，现场记录可展开，完整对话可折叠；返回 / 重练按钮可用。截图：[桌面现场记录](../../docs/qa/3d-debrief/scene-record-zh.png)、[手机现场记录](../../docs/qa/3d-debrief/scene-record-mobile-zh.png)、[手机入口](../../docs/qa/3d-debrief/entry-mobile-zh.png)。

生产访客检查发现了 Zustand selector 内新建空数组造成 React #185 的崩溃，已改为 selector 外使用稳定场景技能 fallback；等到实际报告完成、咨询和刷新后复测通过。见 [已知坑](../80-known-pitfalls.md#访客复盘不能在-zustand-selector-内新建-fallback-数组2026-10-03)。

## 仍需追踪

- [ ] 扩大外部语义盲测。现有校验保证引文 / 来源 / 观察关联，不保证所有解释公正；小样本仍出现额外截止日期、对家人动机的假定、把示例放进解释正文。新建议的可选性、原句时点与用户边界继续纳入评测，不能放宽证据校验来换成功率。
