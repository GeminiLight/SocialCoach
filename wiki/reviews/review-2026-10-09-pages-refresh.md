# GitHub Pages 官网更新验收

用户要求更新过时的官网。范围为 `site/` 与其构建发布流程；没有修改应用业务逻辑、模型配置、主句或论文材料。

## 改动与结果

- 首页按真实场景 → 对练与原话复盘 → 3D → 视频 → 资料 / 研究组织。主要入口指向场景目录、3D、真实对话排练；已有五个双语指南、论文 PDF 与补充材料链接保留。
- 重拍当前正式应用的场景目录、职场第三视角和电梯开局。展示区域做裁切并注明局部；原话复盘引用已有实际示例，保留原图链接。素材来源见 [ASSETS](../../site/ASSETS.md)。
- 官网色板在构建时直接读应用 `globals.css`，OG 和元信息也从相同 OKLCH 转换。原有品牌主句保持一致。
- 修复英文导航中当前语言链接跳回中文的问题。平板测试发现论文引用块的 grid 最小内容宽度撑大页面，通过 `min-width: 0` 修复；未通过隐藏页面溢出来掩盖问题。
- 准确说明共享模型额度、生成时的上下文发送、可关闭的统计与主动反馈。

## 验证

- 静态构建生成 12 个页面；13 个 canonical 地图目标（包含 PDF）和 262 个内部资源 / 链接 / 锚点全部通过。增加图片 alt 与当前语言链接检查，继续在 PR 和发布前执行。
- 浏览器检查中文 / 英文 × light / dark × 1440、1024、768、390、320，共 20 种组合：无横向溢出、缺图或脚本异常。
- 实测主按钮文字对比度最低 14.85:1、所测次要文字最低 5.25:1。这是指定元素的测量，不是全站无障碍认证。
- 主题切换写入本地设置，并更新辅助技术可读的主题名称；英文当前语言点击后仍留在英文；FAQ 可展开；BibTeX 复制显示成功。
- 实测 3D 场景选择与中英文切换；截图未调用模型。正式应用当时共享额度不足，未把本次浏览与拍摄当作模型对练可用性测试。
- 使用标准媒体查询适配窄屏，尊重 reduced-motion。保留无 JS 时正文可见，滚动显现仅在 IntersectionObserver 初始化后启用。
