# 复盘 AI 助手交付评审

用户需要理解复盘里陌生的概念，并询问如何在本次聊天使用。实现了报告内多轮助手、知识卡片问题入口与可编辑起点，回答依次显示原话、解释、示范和作者 / 文献依据。

## 已核对的边界

- 只使用当前场次的公开角色 / 背景、真实双方转录、报告文字与最近六组问答；完整历史保存在本地。隐藏设定与评分增量不进入请求。
- 先核验连续用户原话与本次检索来源 ID，再显示回答；不把模型建议混进转录。模型可以纠正原报告，没有改分或更新熟练度的入口。
- 部署模型与 BYOK 共用任务及校验；失败 / 停止保留问题、完成后原子保存、卸载保护迟到结果。导出沿用完整 sessions，密钥仍与导出分离。
- 引文 / 结构不合格最多重新生成一次，不用代码把捏造的引文替换成另一句真实原话。无法核验时明确失败。格式解析的既有一次重试仍适用。

## 验证

- 共享任务：23 项确定性断言，含中英概念检索、来源、原话、隐私、零发言、连续上下文、段落规范化、有界重新生成及解析失败不记录练习正文。
- 界面：38 项检查通过，包括知识预填、连续追问、刷新、重试、取消、键盘、8 个布局 / 语言 / 主题组合、导出和离开保护。8 次自动可访问性扫描为 0 violation，incomplete 项仍需人工核对。
- 既有 `check-product-ux.ts` 关键旅程（`UX_SKIP_MATRIX=1`）通过，含欢迎、旧档案、知识连接、重练、对话草稿 / 重试、目录状态与暂停键盘路径；未重复全页面矩阵。
- 原有练习策略：19 项检查通过，涵盖全部 46 个语料场景的核心匹配与评估边界。
- 真实模型：三问连续样本通过；本地耗时约 7–15 秒，原话和来源经过共享任务核验。最终样本明确说没有后续反应时无法断定效果；人格问题没有诊断结论。
- lint、TypeScript 和正式构建通过；wiki 审计 0 high / medium，仅保留既有来源记录缺少日期标记的 info。
