# 三桌人物区分验收

用户指出职场、学校、家庭桌像在重复使用同一批人。实际 ID 与台词不同，但脸型变化很小，发型、服装与体型模板高度重复。先前九人几何测试只证明网格有效，无法证明视觉辨识。

## 改动

| 桌子 | 人物外形 |
|---|---|
| 职场 | 陈总：宽下颌、较壮体态、后移发际线、西装领带。林姐：窄脸、挽发、深灰外套与浅色内搭。小周：瘦长体态、短发、蓝衬衫、深色方框眼镜。 |
| 家庭 | 大姨：较圆脸型、卷发、开衫与围巾。妈妈：更矮的体态、短发、绿开衫与浅色内搭。爸爸：灰发、后移发际线、细金属眼镜、燕麦色针织 polo。 |
| 学校 | 许学长：较高体态、年轻眼型、蓬松头发、陶土色外穿衬衫与白色内搭。小月：较细脸型、马尾、浅色圆领上衣。阿凯：刘海、圆框眼镜、深青色卫衣与抽绳。 |

`cast.ts` 使用稳定角色 ID 提供选角档案，体型缩放同时覆盖骨骼、面部、衣服、手与物品。相机、NPC 视线与标签使用真实眼高；下颈与座位锚点保留。人物呼吸 / 眨眼初始相位按 ID 分开，细微倾斜与说话幅度按人配置。动作不改变剧情权限或用户同意。

颜色来自 `globals.css`，人物说明小头像同步发型与服装色。现有存档与人物 ID 不变，切桌无需迁移。没有引入远程模型素材或新增请求。
