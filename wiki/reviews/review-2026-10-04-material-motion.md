# 主站材质与交互动效精修

用户反馈上一轮的横线、序号和硬边分区太多，缺少精致的质感和连续交互。本轮保留温暖纸面与原话批注，以留白和柔和表面替代普通区域的重复线条。

## 已完成

| 问题 | 本轮行为 |
|---|---|
| 页头、分类、推荐与目录全部用线分隔 | 去掉重复横线；推荐为柔和表面，桌面目录两列开放内容，去掉无意义序号 |
| 普通控件偏硬、分区同一材质 | 8 / 14 / 20px 圆角；共享纸面与浮层阴影；导航、输入、阅读和资料形成层次 |
| 筛选展开推动整页，下方投影短暂覆盖按钮 | 工具栏下方浮层；场景位置保持稳定，空间根据窗口和手机底栏计算，内部滚动 |
| 状态切换缺少连续反馈 | 分类与知识类型共用选中表面；页面、标题、卡片、浮层与知识正文使用 100–260ms 的局部反馈 |
| 阅读新条目沿用旧滚动位置 | 切换正文回到标题；手机打开 / 关闭保留展开语义，关闭立即退出键盘访问 |
| 快速输入偶尔丢失筛选条件 | 每次从当前 URL 读取最新条件，避免覆盖尚未进入 React 快照的前一次输入 |
| 减少动效仍可能出现一帧共享投影 | 使用静态选中面并关闭布局投影，浮层直接切换；状态与焦点照常可用 |

保留：首页练习优先级、搜索与返回状态、模型失效接入窗、原话证据、来源、报告、能力估计、草稿与导出。没有修改剧情、模型调用、语料或评分，也没有改写 3D HUD。
