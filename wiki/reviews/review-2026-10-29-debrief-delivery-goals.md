# 复盘交付与练习目标精修

用户授权按“复盘交付 → 场景匹配与目标 → 测试后双站发布”推进。没有增加账号、服务端练习档案、自动运营任务或付费资源；原始反馈与设备级运营材料保留在仓库外。

## 定位与修订

- 原生产站的一条受控复盘成功返回，耗时 68.21 秒；这不是整体成功率，不能把历史缺失报告都归因于模型报错。
- 报告校验完成前不发正文，原连接也没有首字节。现在立即发送空白、每十秒保活，首段非空正文后停止；不修改 `@@final` / `@@error`。空白不代表报告已核实。
- 165 秒任务预算与全部原话 / 语义核对保留；截止明确返回可恢复 504。浏览器另有 180 秒传输上限，取消读取 / 模型请求。模型档位、格式与语义修复次数没有放宽，也不自动重试付费调用。
- 旧记录 / 直接请求若无用户发言，快速拒绝、不调用模型，并提供返回对话 / 换题。正常对话结束弹窗原已拦截零发言，不能将该边界称为正常入口的主故障。
- 真实浏览器复盘同时显示旧模拟“0/2”和独立核对“1/2”；移除旧计数，原目标仅展示最终证据。沟通星数与目标达成仍分开。
- 等待角色设定页可以展开保存的完整原话；慢模型提示、错误重试和刷新恢复保留本地记录。

## 场景与目标

58 个现有场景均有固定练习身份。本轮不改写人物关系 / 权限：准备页增加四种可选回应方向与最多 300 字的自定打算，可取消、换题或排练真实处境。草稿留在当前标签页；进入后随本地档案导出，整场重练保留。不同打算不作同条件对照。

模拟与复盘接收初始偏好，后来的实际表达优先；偏好不是转录、行为证据或替代原目标。准备 / 对话 / 复盘均明确区分这三者。推荐的 `compatible` 也需真实背景引文，缺失 / 虚构引文降为 `uncertain` 并提示确认；字面引文不能单独证明语义相容。

完整对练还复现了唐悦编造“上次我帮你救场”的反向人情债。原保护只用于短练，现扩至完整对练，保留用户真实确认过的经历，质疑 / 否定不算确认。这是窄句型保护，不能声称解决所有虚构往事。

## 可观察性

新增严格元数据 `assessment_stage`：随机请求 UUID、会话 / 3D 练习关联、模式、开始 / 完成 / 失败 / 取消、耗时、状态码和 BYOK；飞书“请求关联”对应脱敏调用日志。不记录打算、转录、回复或密钥。

`completed` 指有效报告抵达客户端，不代表阅读或磁盘写入成功；原 `debrief_view` 兼容，历史缺失不可倒推。关闭页面的取消事件仍尽力送达。ModelScope 本次发布将非敏感 `FEEDBACK_VERSION` 设为来源提交，修正历史一直回退 `0.1.0` 的版本识别问题。

## 验收

- 两项原失败测试先失败后通过：空记录调用模型、核对期间没有首字节；增加取消不得泄漏报告、180 秒截止、偏好不可作证据与隐私字段拒绝。
- 395 项测试（137 core + 258 dinner）、既有语料 / 恢复等脚本、lint、类型检查、生产依赖审计和正式构建通过。
- 日常 Chrome：中文目标选择 / 300 字限制 / 刷新保留、直接与重复拒绝、等待展开原话、报告与本地恢复。旧目标矛盾在相同报告修订后核对。
- 真实 GLM：让步、拒绝、反问、玩笑、修复、续聊及英文拒绝均返回可继续的回复，单回合约 4.2–5.9 秒。样本不代表真实效果或通用语义正确率。
- 本地开发遇已有字体解析错误；相同源文件正式构建通过，开发使用现有 Next webpack 模式，未改字体或供应商配置。
- 双站版本、公网模型交付与移动视口核验将在发布补记记录；实际手机、更多供应商 / 多轮事实与意图仍需扩样。
