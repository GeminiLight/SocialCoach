# 同题邀请卡：实现与验收

用户明确选定[留存与传播评审](./review-2026-10-22-retention-growth-strategy.md)的下一项并授权测试后上线。主线基线 `c9978367`；原目录落后且有四份既有规划修改，完整保留，在独立工作区开发。→ [阶段](../13-stage-e.md)、[规格](../archive/specs/spec-scenario-invite.md)。

## 用户路径

准备 / 复盘 / 短练完成后预览邀请 → 选择中文 / English 和主站 / 国内入口 → 复制邀请、保存 PNG 或系统分享 → 朋友看到唐悦公共开场、角色与目标 → 明确开练 → 自己的独立记录与证据复盘。一次完成后可再邀朋友。

固定 v1 使用已审核场景原件，保留 source。卡片不包含邀请者姓名、转录、评分、底牌、个性化背景、本地 ID 或追踪 ID。不提供私人原话开关，原有练习记录分享继续保留。二维码纯本地生成；没有新模型调用、后端存储、账号、邀请关系或新增匿名事件。接收者练习照常使用既有模型与共享额度，模型与预算配置未改。

## 已验证

- 补充浏览器恢复：剪贴板拒绝、系统分享不支持/取消/失败、图片失败与重试、快速切换语言/入口、关闭回焦、连点开练、返回继续、原档案/姓名保留、未知版本、损坏档案不覆盖。主站 PNG 缩至 360 / 540 宽仍解码正确。

追加正式构建检查：4 组 URL 语言 × 新访客 / 已有相反语言档案通过，服务器首屏、模型提示、按钮、模型设置语言一致且档案不被浏览动作修改；8 组矩阵补查 pageerror 均为 0。手机尺寸公开入口完整两轮、外层地址刷新续接、复盘再邀请均通过。

原件：[浏览器](../../docs/reviews/scenario-invite-2026-10-22/browser/)。本地矩阵使用虚构数据并拦截模型、统计，不发送朋友消息或反馈；真实托管模型检查单列于下方。

测试脚本首次因 CJS 顶层 await、旧按钮名称未匹配而中断，修正测试工具后完成矩阵；不把脚本问题当线上产品故障。PR #43 合并后的最后一次公开入口检查发现正式构建 React 418；开发模式复现并定位为模型提示语言与服务端不一致。原矩阵未检查 pageerror，补充此断言和四组首次访问 / 相反语言档案检查后修复；保留首轮失败记录。
