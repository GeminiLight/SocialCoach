# 文字练习连续性复盘

日期：2026-10-03。涉及 `Chat`、共享 `runRoleplay` 与角色输出解析。对应 [验收记录](./reviews/review-2026-10-03-text-practice.md)。

## 现象与根因

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 用户还在追问，第 6–10 回合就进入复盘；刷新也结束 | 回合数、模型 ended、1.4 秒定时器与发送锁共同控制状态 | 12 起步、每段 +8；仅用户结束，节点可继续输入，限时等待暂停 |
| 长聊后回复只有台词，没有进度字段 | 文字格式助手历史长期只有台词，覆盖了输出合同；末尾提醒不足 | 内部 JSON、每次交换保存真实 meta，老档案不伪造状态 |
| 已完整回复却报中断 | 模型重排键，meta note 未完时前缀提前定型 | 实际元对象闭合后才发稳定前缀，不依赖“必需字段已齐” |
| 截断内容被算成完整台词 | 通用 extractJSON 会修复缺失结尾 | 角色回复先要求真实闭合；已显示草稿不接受后台改写 |
| 人物补造过去失约、截止日期、已同意的安排 | 结构正确并不代表语义符合事实；“具体”被当成可新增事实 | 每个新场景给出事实与未知边界，追问 / 条件提议不等于承诺；私有边界不进入学习者提示和评价 |

格式修复最多一次，只在台词尚未展示时尝试；展示后失败保留用户原话并提供恢复。有限段落仍是有目标的练习，不提供无目标的无限闲聊。

## 验证和边界

13 项续聊、15 项结构流输出、19 项通用政策、7 项存储恢复检查通过。最终真实模型 56 次调用，包含三条 14 回合路径、12 场景入口与旧版本对照；55 次当前版本输出没有格式 / 流前缀失败。样本只使用合成输入，不含用户私密记录。

NPC 可以拒绝和真正离开，用户的继续权不代表强迫合作。结构测试不能证明每句语义真实：仍需玩家盲测，关注称谓自我纠正、隐含承诺、反复谈同一件事。不得把“模型建议收尾”改回系统自动结束。
