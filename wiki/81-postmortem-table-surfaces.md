# 餐具曲面、液体与接触高度

3D 精修的浏览器回放发现三类相关问题：杯脚部分埋入餐垫，第一人称握杯位置让杯底与手部重叠，家庭汤碗看起来像盖着盖子。问题集中于 `build_rooms.py` 的餐具形状和运行时的相对位置，并非贴图分辨率不足。

## 原因

- 新增餐垫后，盘、碗与 `TableCups` 仍有旧高度。物件分别可见，不代表接触关系正确。
- 手臂源的原点在手腕，杯脚的原点在底面；两者直接对齐不能得到抓握。近景离镜头过近又放大了重叠。
- 旋转曲面的面顺序与轮廓外升、内降的方向相反；双面材质掩盖了问题。固定半径液体柱还会穿过收窄的碗壁。汤面较低，低机位只能看见碗沿。改成曲面酒液后，又发现只有杯身网格做了归位，新酒液仍停在制作时的 x=1 原点，形成悬空块。

## 修复与检查

统一餐垫顶面、盘底、碗内底与杯脚高度。按原玩家的握手骨骼核对手指位置，调整杯柄 / 杯茎与手的偏移，并把小屏近景拉远。仍没有完整手部 IK，不能据此宣称所有动作都无穿插。

反转旋转曲面的顶点顺序，并同步 UV 的循环次序。离线制作时逐面断言外侧朝外、内侧朝内、水平内底朝上、底脚朝下；开放桌布与釉色带使用显式的顶部朝向；格式验证器不能代替这项检查。酒液用随杯壁变化的轮廓，汤面半径按填充高度处的内壁确定，汤料少量浸入液面。杯具所有部件统一移动到公共原点，并用导出后的实际节点变换与网格包围盒检查边界；旧酒液 x 范围约 0.922–1.078、节点平移为零，新检查可识别这种脱离杯身的错误。

所有四份相关 GLB 重新导出并验证，再在实际机位看家庭汤碗和举杯。详见[画面与验证](./reviews/review-2026-10-05-3d-framing.md)。

以后加入餐垫、液体或手持物，先核对原点、内外壁与接触高度，再判断材质；同时看低机位和近景，不只看俯视图。
