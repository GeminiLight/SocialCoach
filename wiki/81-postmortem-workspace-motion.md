# 工作区动效集成复盘

2026-10-04 为普通主站加入柔和材质与连续状态反馈时，浏览器回归连续发现多项相关交互问题。没有在这些失败未解决时发布；验证使用本地档案和受控模型响应。

## 现象与原因

1. 展开筛选后立即选择技能，按钮被下方移动中的标题覆盖。大型容器的 FLIP 投影把旧位置上的内容画到了新面板里；关闭后快速点击加载更多也不稳定。
2. 连续选择技能、难度再输入搜索时，URL 偶尔丢失难度。事件闭包使用 `useSearchParams` 的旧快照，后一事件早于 React 收到前一次地址更新。
3. 减少动态效果下，设 Motion 时长为零仍可能产生第一帧投影；CSS 的极短时长也会留下浮层的初始位移。
4. 新增集合与情境可以同时选中，若两项共用一个 `layoutId`，共享选中表面出现冲突。

## 修复

- 筛选改为有边界的工具栏浮层，目录不随展开移动。按窗口、触发处与底部导航计算可用空间；关闭即 `inert`，Escape 恢复入口焦点，外部点击关闭。
- 事件从 `window.location.search` 构造下一次条件，保留同一 URL 的已完成输入。
- 减少动效直接渲染普通选中面，禁用布局投影；浮层的 transform / transition 显式取消。
- 情境是一个独立共享选择组；可并选集合保留静态选中面，避免共享元素重复。

## 防复发

`check-material-motion-browser.ts` 逐帧检查连续选择与收尾、浮层不移动目录、快速反转、可达点击点、减少动效、组合选择和小窗口。原有工作区检查继续验证组合筛选、刷新、返回、清空与加载更多。

原则：先验证过渡期间能否立即操作，再评判动画是否好看；共享选中面只属于互斥选择。父容器不要整体 transform，否则固定操作条会改用该容器作为定位基准。
