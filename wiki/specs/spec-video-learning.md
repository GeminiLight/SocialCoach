## 用户任务

用户从一段具体的沟通示范中看见不同回应，再进入同一处境自己开口。视频并入既有学习区，默认视频、理论、案例与收藏四种内容；不增加主导航目的地。保持产品的实际练习定位，观摩材料承接既有对练与原话复盘。

## 当前边界

- 当前两条用户提供的原创虚构动画：《饭局上，领导替你答应了》→ 职场饭局 `work-toast`；《刚从 HR 出来，领导当众问你是不是要走》→ 电梯口 `elevator-privacy`。练习按钮按对应场景显示名称，后续沿用同一数据结构。
- 采用 HTML 原生播放器，720p MP4 / faststart，首次不预取影片、不自动播放，移动设备行内播放。关键片段与引用都能跳转到实际时间。
- 中文原片、中英文字幕与完整文本；英文界面默认选英文字幕，中文原片保留烧录文字。字幕时间依最终成片：饭局 1696 帧、电梯 1505 帧，均为 30fps；不按早期分镜的预计时长生成。
- 拆解引用影片而非评价用户。时间承诺需可完成、模糊交付范围需继续确认、对方让步并不保证复现；不标观看完成为能力提升。
- 无需先填目标或配置模型即可访问 `/learn`。学习区不触发模型接入检查或自动接入弹窗；离开进入 AI 功能后恢复既有门控。观看、字幕、搜索与收藏没有模型请求。
- 收藏沿用已有本地档案与导出 / 恢复 / 重置。播放位置只在当前播放器中使用；网络重试保留位置，离开页面不承诺跨次续看。
- 饭局跳转 `/3d?scene=work&opening=work-toast`；电梯跳转 `/3d?scene=elevator&opening=elevator-privacy`。均使用已有确认流程，不带 `restart=1`，不会直接覆盖正在练习的存档。

## 数据与实现

`src/data/video-lessons.ts` 保存双语标题、简介、技能、来源、影片 / 封面 / 字幕、关键片段、转录、引用式拆解和练习目标。`VideoLesson` 负责真实播放状态、字幕、片段定位、文本与重试。`/learn` 统一检索与收藏，保留既有桌面索引 / 阅读面板及手机折叠模式。手机仅打开时挂载视频；关闭和切换内容会卸载，隐藏页面时暂停。手机展开后定位到播放器，返回目录恢复索引焦点。

字幕由 `scripts/prepare-video-captions.ts` 从已核对的转录生成并提交为 VTT；构建无额外视频渲染依赖，无新增 API、账号或服务端学习存储。影片随现有 public 资产提供，扩容时再按实际流量选 CDN / 对象存储。

## 五期 H 社会科学短片与媒体加载（2026-10-26）

- 新增《透明度错觉》《弱关系的力量》《前台与后台》《自我实现的预言》《一点偏好，一片分隔》，保留原饭局、HR 电梯两条示范，共七条。五期均沿用用户选定的 H 配音。用户在本轮明确确认已取得适用于 SocialCoach 产品公开使用的书面授权并授权双站上线；助手未查阅授权文件，不据此推定模型权重可再分发。
- `VideoLesson.kind` 区分情境示范与概念短片。短片引用实际旁白、标明理论 / 研究 / 模型与虚构边界、提供原文链接；不伪造对应的 3D 开局，练习入口回到 `/arena` 由用户选择。旧示范保持原来的 3D 确认入口与收藏 ID。
- 本地一次性导出为 720×1280 / 30fps H.264、AAC 96k、faststart。五片总大小 153,677,094 → 21,065,050 字节，约减少86.3%；每条3.6–5.3 MB。原片与工程不进入发布目录。完整解码通过，与缩到720p的原片 SSIM 为0.9811–0.9832；这不是主观音质结论。
- 封面与目录缩略图分别输出720 / 256宽的 WebP。`social-science-media.json` 记录真实字节、帧数、源 / 导出哈希；MP4、WebP 文件名带内容哈希，仅这些确切路径设置一年 immutable 缓存。字幕保留正常重新验证，纠错不困在长期缓存中。
- 首次只显示封面，`video` 不带 `src`、不挂 `track`，未激活的原生媒体控件不向辅助技术暴露空资源状态。用户明确播放或点击时间点时，才在同一手势内连接影片并调用 `play()`；不用效果钩子自动播放。字幕也只在此时挂载，英文界面默认显示英文翻译。
- 手机关闭 / 电脑切换以课程 ID 卸载播放器；清理时 pause、移除 src 并 load，释放旧媒体请求。只阅读文本、检索或切换课程不会下载影片。保留后台暂停、失败提示、重试和时间点恢复，不增加模型调用、观看积分、档案字段或 API。
- 真实 Chrome 本地请求日志证明：初次进入、选择第五期、展开转录均为0个 MP4 / VTT 请求；点击章节后只有第五期 MP4；切换到未播放第二期仍没有新影片请求。390px 中文界面展开第三期不请求影片，点击章节才请求第三期；关闭后回到折叠列表。窄屏为浏览器内 iframe，不冒充实体手机验证。

维护入口：`app/scripts/prepare-social-science-media.py --source-root <本地五期工程>` 为显式本地导出工具，线上构建直接使用已提交资源，不安装 ffmpeg。`prepare-video-captions.ts` 从核对过的双语真实转录生成字幕。
