# 十二个文字场景的条件式剧情

状态：实现、模型回放完成，网页试玩与发布进行中。补充 [共同剧情标准](./spec-scene-craft.md)，不把 3D 待验项目一起标完成。

目标是具体阻力、可回应的决定和部分谈成后的后果。以下是 SocialCoach 原创虚构设计，不是现实案例、礼仪规范或标准解法。来源随原场景 `source` 记录。

| 场景 | 值得继续的决定 |
|---|---|
| 电梯人事追问 | 保密之后怎样问负责人、取得官方联系人 |
| 五分钟帮忙 | 讨论 / 列问题 / 改稿的范围，对老板怎样描述帮助 |
| 群里甩锅 | 原清单与追加项怎样公开表述，谁确认后续 |
| 父母突访 | 电话、拿饭、接待分别协商，下次先问 |
| 姐姐账单 | 退款未知时各自愿承担多少，未来预算怎样确认 |
| 朋友拒绝建议 | 听、一起想办法或暂停，怎样开口说损失 |
| 朋友没邀约 | 不替对方决定，也不承诺所有聚会必带上对方 |
| 伴侣要求定位 | 约定迟到与普通忙碌分开，安排可以撤回 |
| 旅行变更 | 钱与假期损失分开，退改 / 独自出行 / 取消待本人决定 |
| 校园截图 | 更正配文、移除截图、未来许可与接活分别谈 |
| 窗口插队 | 短询问不等于完整业务，工作人员规则待核实 |
| 聚会直播 | 画面、声音与回放分开，不保证删除所有副本 |

`Scenario.simulationDirection?: L` 随场景进入设备档案、导出、服务端和 BYOK。只有模拟视图读取；适配、提示与点评不读私有后续。旧快照缺字段仍可用，不按 ID 偷换自定义内容、不覆盖旧对话。新开一局取得新语料。

条件不是固定阶段或回合计时器。先回应当前话；拒绝后保留其他选择，错误后留修复路。不新增模型调用、公开面板、固定台词或自动停局。

验收：十二场景各两条四轮路线，覆盖拒绝、有限让步、反问、玩笑、修复和续聊；另有跨段长聊。实际台词核对事实、范围与不同后果，结构通过不等于真实感通过。三个场景保留只移除本字段的基线。网页核对连续发送、部分成功后的分歧、刷新与历史、继续、手动收尾。

模型仍会编造细节或误记承诺；创作指令不是通用事实校验器。证据和限制见 [评审](../reviews/review-2026-10-04-text-play.md)。
