# 用户反馈修订：场景、证据与完整体验

状态：实现已落地，本地验收完成核心流程；设备与更多模型盲测继续跟踪，尚未发布。来源：[2026-10-04 用户反馈核验](../reviews/review-2026-10-04-user-feedback.md)。主线是主站，独立 3D 原型同步不作为交付条件。原始反馈文档、截图及包含个人信息的附件不进入仓库或模型。

## 交付范围

| 编号 | 行为与边界 | 验收 |
|---|---|---|
| D1 | 十种 3D 开场共享公共简报：我的身份、已知资料、目标、人物、尚未确认的事实。提供可演练的虚构项目，不揭示 hidden | 界面、导演和复盘读取同一资料；办公室新手可以直接说明方案与风险 |
| D2 | 走动对应可达动作与实际结果，现场提示说明用途 | 走近不产生私聊、同意或额外评分；动作记录和模型输入一致 |
| D3 | 证据式自然收尾，常驻轻量复盘入口，继续保持原历史 | 收尾引用当前双方原话；用户选择继续/复盘；预算仅暂停；重载保留收尾与继续状态 |
| D4 | 原目标、当下意图、沟通表现分开 | 举杯/未知饮品不推断饮酒或戒酒成功；主动改变目标不推断屈服 |
| D5 | 普通口吻、各自利益、真实连续分支 | 不编造未知权限和验证结果；五回合以上合成路线验收，不用格式检查代替语义评价 |
| D6 | 选择页明确当前冲突 | 相亲介绍明确照片、联系方式、见面分别未承诺；十个开场中英文可读 |
| U1 | 分项背景和自由输入共存；支持本地文件/截图提取、编辑、脱敏后显式发送 | 清晰的格式/大小限制；附件原文件不上服务器；仅已确认的背景进入模型；草稿可恢复 |
| U2 | 场景目录元信息分组清楚、保持密度 | 类别/难度/技能/时长固定层级；手机、英文和桌面均可扫描 |
| U3 | 准备页身份背景前置，压缩装饰，辅助文字可读 | 1366×768、1280×720、200% 缩放、手机不遮挡主要内容 |
| U4 | 分享预览、保存图片、复制短文、设备支持时分享文件 | 私人原话默认不含；取消安静处理，其他失败给退路；不分享本地练习 URL |
| U5 | 本地头像上传、裁切压缩、去元数据，保留预设与恢复 | 全站头像一致；可导出、重置；不传模型，不用于自动生成 3D 人脸 |
| U6 | 完整历史宽面板、引用跳转、桌面可调分栏 | 最小宽度、键盘、持久化；手机独立面板；阅读位置不因切换丢失 |
| E1 | 教练验证引用的实际含义与时序 | 已回答不评成未回答；对方未接受不等于未表态；替代表达只使用当时已知事实 |
| E2 | 未展示报告前有一次有限格式修复 | 仍失败明确报错；拒绝、取消、网络错误不盲重试；不以空评价冒充成功 |
| E3 | 未知事实不补成限制或已完成事件 | 权限未确认不等于不能查；未经确认不能宣称已验数据或接受任务 |

## 验收方法

核心状态、持久化、文件限制、证据检查和失败恢复使用行为测试，先复现再修复。完整报告一次格式修复、最多两次字段级语义修订，每次重新检查整体；全部失败保留原话，不展示或评分。共享教练覆盖文字版和 3D。模型语义使用核验阶段的另写合成案例，不发送原报告；模型结果保留本地，结果与限制写入核验记录。页面用实际浏览器检验，不改写用户正在使用的草稿。界面文字中英文，颜色与宽度由全局设计 token 管理。附件解析按需加载，不增加 3D 启动开销。

新增默认资料属于原创虚构演练素材，其 source 为本 spec；未知事实保持未知。背景、文件和头像仅设备保存，导出可携带，重置可清除。发送模型之前的预览是实际发送内容，不隐藏上传步骤。

完成后更新 API、架构、设计原则、roadmap 与 backlog 对应项；全部验收完成后再归档此 spec。
