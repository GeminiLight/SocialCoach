# 这一句，重来（E3）

2026-10-22 用户选定并授权实现、测试与上线。依据 [Stage E](../13-stage-e.md) 与[留存策略评审](../reviews/review-2026-10-22-retention-growth-strategy.md)。目标是缩短从复盘到再次开口的距离；不据工程验收宣称留存或现实能力改善。

## 一个场景、一个动作

`office-quick-favor`：同事唐悦请求帮改六页，用户自己有 16:30 的报告截止。练习把帮忙的范围、时间、责任说清。只从原场第一句用户回应前重来；前面须只有 NPC 开场，可忽略教练提示，不能有沉默或其他已经发生的行动。不开放任意回合、3D、自定义或多 NPC 回滚。

入口在该场已完成复盘里。保留用户当时背景、身份和 NPC 原开场；不带入原回答、后续承诺、后续披露和原场评分。建议两轮，可在完整一轮后回顾，最多四轮；不能为赶结束强制对方妥协。用户可以拒绝、反问、开玩笑、修复、继续。

## 记录与反馈

- 子路径 `/practice/[id]/retry/[attemptId]`；子记录放在原 `Session.keyTurnAttempts`，包括版本、原回答指针、语言、时间、修订号、新转录与独立回顾。原场消息和报告不改。
- 至多一个未完成短练，返回或刷新可继续。草稿限当前标签页；发出的用户原话先保存，未完成 NPC 回复不入档。取消请求、旧修订和旧页面的迟到回复不能覆盖新状态。存储冲突沿用全站保护与恢复提示。
- 导入导出保留子记录；旧档无该字段兼容。同 ID 不同分支备份拒绝静默合并，要求用户明确选择。
- 原第一句和本次第一句并排，点击各自打开独立完整转录；相同表达也如实呈现。只展示能逐字引用本次用户原话的沟通观察；不展示短练评分，不更新能力、整场次数或独立重练对照。
- 模型复用 roleplay / assess 与托管 / BYOK 共享验证、预算和取消。增加可选 `practiceMode: 'key-turn'`，限此场景和四句用户回应；不新增模型供应商、账号或服务端练习存储。暂不增加短练专用匿名事件，不能从已有整场事件推算本功能留存。
- 短练 NPC 使用既有 smart 模型档位（托管与 BYOK 一致）；其他文字对练继续 fast。快速模型的多轮人工审阅仍出现虚构关系 / 时间，因此优先精度。仍为每次 55 秒、最多两次逻辑调用、1,800 输出 token；费用随配置而变，不宣称与原 fast 成本相同。

## 验收

1. 原场 / 本次原话分离，无未来事件泄漏；原场成绩、能力与历史不变。
2. 草稿刷新、待回复刷新、暂停重试、回顾失败恢复、四轮上限、旧修订拒绝和备份恢复。
3. 中英 × 明暗 × 手机 / 桌面；引用打开正确转录，无水平溢出，关键区域无可访问性扫描错误。
4. 真实模型六类行动与双语回顾人工审阅。模型判断与可复现程序保证分别记录。
5. 应用检查、正式构建、PR 检查通过，双站发布后从公开入口复验。模拟手机视口不能替代真机，也不能证明用户愿意重练。

## 发布后的观察

邀请试玩者自行找到入口，描述这次与原场的差别，观察是否主动换一种开口；记录实际完成 / 中断原因。任何核心不可用、档案丢失或隐私问题优先。下一候选仍需单独选定，不扩展到自动持续开发。
