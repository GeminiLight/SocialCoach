# 3D 动画美术方向提案

状态：方向探索与概念图，尚未替换主站模型。用户提出当前人物不像真人，希望考虑 3D 动画风以降低恐怖谷。本提案针对美术与呈现，剧情阻力、信息边界、证据式复盘保持现有定位。

## 推荐

主推“成熟角色动画”：人物明显是动画角色，仍能辨认成年人、年龄、身份与关系。头身比轻度夸张，眉眼和嘴角清楚，皮肤哑光、头发成组塑形、服装保留剪裁；家具和食物采用同一套简化程度。场景中的社交压力由对方的眼神、停顿、动作和要求形成。

三种可比较方向：

| 方向 | 优点 | 取舍 |
|---|---|---|
| 成熟角色动画（主推） | 清楚的年龄与身份，表情可读，能承载职场 / 家庭冲突 | 需要重新设计脸、头发与表情，不能只改变旧皮肤材质 |
| 图形卡通渲染 | 识别快、画面清爽、适合传播 | 描边与分层光照要保持稳定，氛围更像漫画，仍需验证真实感 |
| 柔和手作风 | 亲近、有记忆点，能呼应教练 IP | 可爱感容易盖过成人饭局的分量，须用姿态与演出来维持身份感 |

## 一致性与真实感

研究支持检查各部分写实程度的一致性：MacDorman 与 Chattopadhyay（2016）在所测人形素材中发现，降低特征写实程度的一致性会增加怪异感。这不是“卡通一定无恐怖谷”的结论。我们据此选择统一眼睛、皮肤、头发、身体和环境的美术方向，减少半写实混搭。[作者机构存档](https://scholarworks.indianapolis.iu.edu/items/d82b9253-19d7-49a4-87f6-88ea71f80c08)

Tinwell 等（2011）的虚拟角色研究还提示，说话时缺少上半张脸的表情会影响怪异感。因此动画原型需检查口型、眉眼和注视的配合，不能只把皮肤平涂。[论文出版页](https://www.sciencedirect.com/science/article/abs/pii/S074756321000316X)

真人照片级外观不是本产品的验收目标。年龄 / 权力关系、看向谁、犹豫或不满、握杯和资料的接触、用户说话后的反应，是需要真实可信的部分。角色不会因外观亲近而在对话内讨好用户。

## 最小可检验原型

先制作一位职场领导和同桌环境样段，确认近景与演出，再扩展 15 位 NPC。保留现有骨架 / 场景坐标 / 存档接口，能复用的动作继续复用；不要同时长期维护写实与动画两套用户模式。

- 看名字前，能读出领导的年龄、身份与此刻态度；三位同桌的轮廓 / 发型 / 身形有明显区别。
- 中性、施压、斟酌、不悦、接话五类状态可读；没有常驻笑脸、巨瞳或无意识瞪眼。
- 眨眼、说话、看旁人、抬杯连续自然；眼球、嘴、牙齿、头发、脖颈和衣领没有明显穿插或分离。
- 桌面和 390px 小屏能看清表情、手与物件；第一 / 第三人称和移动仍正常。
- 人物、房间、食物、灯光统一风格。概念图不当作运行截图；必须在实际 WebGL 场景录制 / 回放。
- 本机与真实手机分别测冷加载、帧率、纹理与内存。动画风不自动保证轻量；不靠高分辨率照片、全屏描边后处理或预加载全部角色制造样稿质量。

概念图用内置 imagegen 生成，以当前饭局截图作为构图和角色关系参考；仅供方向比较，不属于运行时资产。

## 概念图比较

这些图片由内置 imagegen 生成。用于比较视觉目标，不代表已能在浏览器内实时渲染，也没有替换当前 3D 模型。

### A · 成熟角色动画（推荐）

年龄与身份较清楚，表情和注视方向可读。实际模型应继承造型与材质的简化方式；不必复制样稿的高精度织物、灯光或景深。它在亲近感、成年人气质和情境分量之间最符合当前产品。

![成熟角色动画](../../docs/art-direction/3d-animation/a-adult-animation.png)

### B · 图形卡通

更平面化、轮廓更清楚，家具和菜品也降低纹理噪声。可以作为偏游戏化的候选；需验证描边 / 阴影在移动镜头下是否稳定。

![图形卡通](../../docs/art-direction/3d-animation/b-graphic-toon.png)

### C · 手作黏土

触感和记忆点强。圆润、点状的眼睛会限制注视和细微情绪的表达，若用于正式排练，需保留更清楚的眼睑与视线变化；目前不作为主推。

![手作黏土](../../docs/art-direction/3d-animation/c-handcrafted-clay.png)
