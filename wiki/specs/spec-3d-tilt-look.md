# 手机倾斜视角与视线选人

日期：2026-10-05。主仓库 `/3d`；默认关闭，当前仅本地实现。

## 体验边界

- 「更多」内开启手机倾斜视角；需要时由这次点击请求浏览器方向权限。首次有效读数以当前握姿为中点。左右倾斜为有界环顾，回到握姿回正；拖动、摇杆和手工选人继续可用。
- 使用投影到屏幕的重力方向，而非直接把 gamma 当成视线。横竖屏统一，避免竖直握持时 Euler 分量翻转造成镜头跳动。水平放置无稳定方向时等待重新校准。
- 1.5° 死区、最大 ±36° 镜头偏转，帧率无关的指数平滑。不增加上下摇晃或画面滚转；第三人称只转视线与玩家头部，不移动 NPC、玩家或改变导航方向。
- 输入焦点、模态窗口、隐藏标签页和窗口失焦暂停 / 归中；恢复、切场景、切视角、屏幕旋转和归中操作重新校准。减少动态效果时停用倾斜。关闭、卸载及无数据超时释放监听器；迟到的授权 / 读数失效。
- 首次收到可用方向数据后同时开启视线选人。「视线选人」也可单独开启，支持手动拖动 / 键盘环顾。小准星遵循真实投影中心和 HUD 避让。
- 对准可见人物，镜头稳定停留 0.7 秒后更新已有的「对谁说」。快速扫过、目标重叠、屏外、墙 / 门 / 家具 / 其他人物遮挡时不切换；没有新目标时保留之前的对象。
- 开始输入、收音、已有草稿、等待回复时锁定对象。手工下拉选择或人物「对谁说」会关闭自动选人；在更多中明确重新开启。选择对象不等于私聊；仍遵守在场的人听得见。
- 语音沿用可编辑草稿与确认开口，不自动开启麦克风或自动发送。方向数据只用于当前镜头，不上传、不写入存档。自动选择后的对象沿用已有 targetId 数据流。

## 验收

权限允许 / 拒绝 / 不支持 / 非安全连接 / 无有效数据 / 迟到授权、左右 / 死区 / 限幅 / 竖直握姿 / 横竖屏、暂停 / 回正 / 卸载、两种镜头且 NPC 不移动、稳定选人 / 快扫 / 模糊目标 / 遮挡、手工优先 / 草稿锁定 / 语音锁定。

代码与受控方向读数可以验证逻辑与相机响应，不能替代 iPhone Safari、Android Chrome、微信浏览器的真实传感器授权、手感与性能验收。

接口依据：[W3C Device Orientation and Motion](https://www.w3.org/TR/orientation-event/)（2026-10-05 查阅）；安全上下文、用户点击授权、beta / gamma 坐标与屏幕方向。
