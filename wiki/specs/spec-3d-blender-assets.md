# 3D 资产重建：Blender 制作与浏览器验收

状态：主站实现、桌面与手机视口验收完成；真实手机冷加载、内存和帧率仍待补测，因此暂不归档。发布与测量见 [体验验收](../reviews/review-2026-10-03-3d-blender.md)。

## 已交付范围

用户反馈人物面部、身体连接和场景割裂。本轮从陈总 / 职场样板扩展，重建了 15 位独立 NPC、玩家、两个第一人称手臂、五个房间及茶杯 / 酒杯，共 24 个网页 GLB。运行时替换旧程序化人物和家具，保留主站剧情、模型 / BYOK、语音草稿、存档、历史与共用复盘。

- 人体使用有许可的 MakeHuman / MPFB 基础网格，头颈、躯干、四肢和衣服共享骨骼；每人额头 / 下颌 / 鼻形 / 脸颊使用独立中性形变，并按年龄、性别、体型、发型、灰发、眼镜和衣着区分五组人物。来源、作者、许可和原始文件 SHA-256 在 [素材记录](../../app/public/3d/ATTRIBUTION.md) 与 [sources.json](../../app/public/3d/sources.json)。MPFB 的 GPL 工具代码不进入仓库，素材另有 CC0 许可。
- 每个人包含坐 / 站 × 待机、举杯、展示手机、伸掌、抱臂、前倾，共 12 个命名姿态；表情形变默认中性，运行时叠加眨眼、低幅口型与视线。杯子和手机附着右手骨骼，不从动画推断用户发言或承诺。
- 重建职场包间、家庭餐厅、学校聚餐、电梯口 / 轿厢、开放办公室；统一实际尺度、木纹密度、材质与照明。保留电梯门、按钮、地面、白板与资料的稳定交互名称；门仍受原来防夹与暂停逻辑控制。
- 第一 / 第三人称按实际导出的眼高定位，NPC 位置独立。第三人称镜头选择受墙体影响较小的一侧，并约束在玩家所在电梯空间；第一人称手部来自同一份玩家网格。
- 仅加载当前房间和选角，几何 / 贴图缓存复用、实例骨骼 / 材质独立；不会将全部人物塞入首页或 Service Worker 离线外壳。Draco 解码器随主站提供。

## 制作与维护

实际环境：Blender 5.2.2 LTS（d13f752e3b9c）、MPFB 2.0.17 / afb9f530a7c2741dedb8df0ebae2e0b183caec21、Three.js 0.180.0。使用独立后台 factory-startup 进程，无需连接 MCP，也不改用户已打开的 Blender 项目或偏好。

22 份人物 / 房间 / 道具的可编辑、贴图打包 `.blend` 保存在主仓库忽略目录 `.blender-work/generated/`；制作脚本、素材清单、导出 GLB 和完整性清单入库。重新导出后必须运行 finalize 更新模型 hash 与眼高，随后验格式、动作和浏览器画面。详见 [复现流程](../../app/scripts/blender/README.md)、[导出机制](../refs/blender-gltf-pipeline.md) 和 [骨骼问题复盘](../81-postmortem-3d-rig.md)。
