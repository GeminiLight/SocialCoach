# 全仓质量修订

来源：[全仓评审](../reviews/review-2026-10-05-repo-architecture.md)。本轮复核 R1–R13 并修复可由仓库负责的契约，不把推测当缺陷，不以合成检查代替模型盲测或平台验证。

## 边界

- 主仓库唯一开发主线；不维护两套 3D 实现。
- 档案留设备，保存失败保护内存与旧档案；不加入账号或服务端转录存储。
- 证据绑定独立场次／真实原话；反思与底牌回看不生成无证据评价。
- 能力估计与累计练习分开，允许新证据纠正；不是临床／招聘评分。
- API、BYOK 共用运行时契约、取消和总时限；匿名额度元数据与档案隔离。

## 交付与验收

逐项采用评审中的反例和验收条件；先免费确定性检查，再正式构建与受控网页验证。具体运行结果写入本轮修订评审，未核实的平台配置和模型整体质量保持未验证。

| 范围 | 目标 |
|---|---|
| R1/R3/R5/R10 | 真实身份、原话、输入输出契约；无证据时拒绝或保留未知 |
| R2/R11 | 档案结构、写入状态、冲突保护、3D 内容快照 |
| R4/R8/R9 | 多场能力估计、证据学习摘要、双语与关键时序检索 |
| R6/R7/R13 | 有界输入与调用、取消、部署限额边界、匿名阶段观测 |
| R12 | 统一免费检查入口、应用 CI 与冻结反例 |
