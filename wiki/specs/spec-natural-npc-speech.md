# NPC 自然语音与等待上限

2026-10-08。用户试听 MiMo 样例后反馈更像人，希望避免增加练习等待。正文继续来自原 NPC；语音合成只读最终接受的台词，不优化文字、不读取隐藏动机、不做声音克隆。

- 文字及输入先出现；开启朗读后，默认共享模型使用自然语音。设备不支持 / 未解锁、个人模型模式、用户选择设备朗读时不调用共享 TTS。
- `/api/speech` 将真实 PCM 音频块转发到浏览器，24 kHz / PCM16LE / 单声道。首次可播放样本最多等待 3.5 秒，超时或生成失败降级到设备朗读；随后一分钟不重复请求自然语音。已经开始播放后断流不重读整句。
- 文字多角色及 3D 主回复 / 插话保持原顺序。开麦、发言、关闭朗读及离开页面会取消旧请求和音频；弹窗 / 隐藏页面暂停声音。回复计时包含语音准备和播放等待，不把它算成用户沉默。
- 预置音色按 3D 既有虚构角色的年龄 / 性别选择，文字角色用默认音色。声音不携带角色私有方向。
- 语音与文字模型可用性独立。服务端继续受共享预算及限流约束，流取消 / 完成释放并发名额；不记录台词、音频或密钥。配置检测不代表实际可用。

验收：真实流首包与浏览器首声分别记录；首块到达、超时、断流不复播、暂停 / 恢复、麦克风、切页、个人模型 / 设备模式无共享请求，存档偏好保留。实测和边界记录见 [语音验收](../../docs/reviews/mimo-speech-2026-10-08/README.md)。自动浏览器与接口检查不能代替 iOS 真机和用户试听。
