# 3D 人物几何与关节连接复盘

用户连续指出人物面部不自然、身体连接粗糙。远景截图与构建成功不足以验证程序人物；近景、侧面、背面和动作转换揭示了同一模块内多个问题。

| 现象 | 原因 | 修复 |
|---|---|---|
| 鼻子中央分明暗、发际线锯齿 | UV 接缝法线独立；头发椭球与真实颅骨不一致 | 接缝法线平均，头发使用颅骨截面与前缘深度约束 |
| 眉毛 / 嘴唇像贴条，脖子在转头时脱节 | 叠加管状五官，头以脸中心旋转，颈部另有刚性圆柱 | 贴面渐细眉形，唇部体积 / 色差融入皮肤，面颈连续网格与下颈固定权重 |
| 肩、肘、膝像拼接玩偶 | 上下肢各自是闭合刚性零件 | 衣身到袖子的完整表面、连续裤腿，骨骼权重控制肩肘膝弯曲 |
| 举杯后袖口出现暗色穿透、手腕与杯子错位 | 袖口顶点仍有躯干权重；手和杯子分别定位，Euler 补偿不能抵消组合旋转 | 袖口全权重绑定前臂，增加合理叠合余量；手和物件共享腕部枢轴，以世界四元数补偿 |
| 调整材质后衣身被拉到身体之外 | `SkinnedMesh.bind(skeleton)` 重新计算已经运动的骨骼逆矩阵 | 明确传入单位绑定矩阵，保留骨架创建时的静止逆矩阵；增加重建回归 |
| 新网格出现缺口 | 表面提取的三角形缓冲区不足 | 提供充足缓冲区并校验每条边有两个相邻三角形，不能忽略构造器警告 |
| 换桌仍像同一批人 | 九个 ID 只有小幅面部比例变化；三种发型 / 衣服模板重复，身体形状从 bob 发型推断 | 独立选角档案，脸型、眼型、发型、体型、服装和动作变化共同区分，三桌远景实看 |
| 外穿衬衫的内搭出现碎片闪烁 | 内搭衣片和衣领使用相同曲面抬升量，产生共面叠层 | 衣领单独提高一层；敞开衣襟的缝线与纽扣放在外侧，不在内搭中央 |
| 换新局后玩家仍带着上一桌的转头姿态 | 玩家 ID 不变，暂停时的姿态缓存只按角色 ID 重置 | 新 Actor 对象触发姿态与时序重置，第一帧直接恢复实际朝向 |

## 今后的验收边界

- 静态几何检查：有限坐标 / 法线、预算、接缝、闭合边、眼睛和发际线深度、衣片贴合。
- 动态几何检查：权重和为 1；胸口 / 下颈 / 髋部锚点固定；袖口完全跟随前臂；资源重建不能改变绑定姿态。
- 视觉检查：九位角色的面部近景，正面 / 侧面 / 背面，举杯 / 抱臂 / 递手机，坐下 / 站立，以及实际包厢和手机。临时检视页面不进入发布。
- 数学测试证明几何约束，不证明审美或照片级真实。扫描人物、专用面部绑定与更复杂接触动作仍是独立资产工作。

本轮共 78 项饭局测试通过，详情与截图见 [人物连接验收](./reviews/review-2026-10-03-3d-anatomy.md)。

后续三桌人物区分另通过 100 项检查，包括不同体型下的头颈绑定、真实眼高、两种视角的手机 / 桌面取景；见 [人物区分验收](./reviews/review-2026-10-03-3d-cast.md)。数学约束与视觉差异分别验收，不能把九个不同 ID 当成九张不同的脸。
