# 产品提案：SocialCoach · 社交教练

## 产品愿景

把「难谈的那场对话」从一次性赌博变成可训练的技能。专家教练能提供阻力、判决和重复次数，但稀缺且昂贵；LLM 让这三样可以规模化。长期目标是成为用户在每场重要对话前会打开的地方，并在多轮之后让他看见自己反复栽在同一个位置。

## 产品定位

**卖 performance，不卖 acquisition。**

整个沟通品类（《关键对话》、非暴力沟通、技巧帖、课程、播客）都在卖「让你知道」。目标用户大概率已经买过两三样，知道该用「我」开头、该先共情、不该翻旧账——然后对方叹一口气，他就让步了。

知道和做到之间那道沟，就是论文里的 **acquisition deficit（不会）vs performance deficit（会但做不到）**。全世界在卖 acquisition，performance 这半边空着。SocialCoach 是唯一把这道沟当第一性问题来建的产品：给阻力、给压力、给判决、给重复次数。

**敌人是「建议」，不是 ChatGPT，也不是同类 App。** 把 ChatGPT 当对手会把产品讲成「一个不顺着你的 ChatGPT」——那是功能不是产品。

## 不做什么

- **不做临床评估、心理诊断、危机干预。** 熟练度是模型估计值，UI 必须标注为估计。涉及自伤 / 他伤的输入不在产品能力范围内。
- **不做招聘、绩效、录用评测。** 任何把分数用于对人做决定的场景都不支持。
- **不做纯建议型内容产品。** 不做「沟通技巧文章库」「话术模板大全」——那是敌人的产品形态，做了就自我抹除定位。
- **不做讨好型 NPC。** NPC 不能因为用户态度好就让步，不能提前吐露 `hidden`，不能在对话内跳出角色做教练。这是与聊天机器人的唯一区分点，任何削弱阻力的改动都要按定位问题对待。
- **不做无证据的评价。** 复盘里每条判断必须引用转录原话。没有证据的评价一律不出现，包括「你表现不错」这类空话。
- **不做账号体系与服务端存储。** 零注册是留存前提之一，数据留在设备上、可导出。引入登录 / 数据库需要重新论证。
- **不做通用聊天入口。** 没有目标、没有回合上限、没有复盘的自由对话不属于本产品。
- **不擅自扩语料。** `wiki/` 与 `src/data/corpus/` 里每条理论 / 案例都要有 `source`。不允许生成无出处的「策略」。

## 目标用户

产品有两类客户，必须分清，因为获客与留存来自不同的一类。

| 用户 | 核心场景 | 当前替代方案 | 痛点 |
|---|---|---|---|
| **A｜明天有一场对话** | 晚上 11 点，明天要谈加薪 / 要拒绝朋友 / 要跟伴侣摊牌 | 在脑子里反复演；找朋友吐槽；让 ChatGPT 扮演对方 | 有日期、有痛感、拖了几周还没说。脑内排练没有阻力，朋友和 ChatGPT 都会同意他 |
| **B｜想变成会说话的人** | 没有具体事件，想系统性变强 | 买书、上课、收藏技巧帖 | 知道了很多，一到现场还是做不到。没有反馈、没有重复次数 |

**A 领先，B 承接。** A 有搜索行为、有截止日、获客几乎免费（`corpus` 里的场景标题就是他的搜索词）；但谈完就走。B 无触发点、获客极贵；但留存靠打卡与成长可见。

**复盘是 A→B 的转化引擎，不是一个功能。** 当报告让 A 看见自己有个反复出现的模式（「每次对方一提高音量你就让步」），急性问题变成慢性问题，他自己变成 B。任何削弱复盘的改动都在砍转化。

## 功能矩阵

|---|---|---|---|

## 研究基座

论文：Wang et al., *SocialCoach: Personalized Social Skill Learning with Agentic Tutoring and Practice*, arXiv [2606.04155](https://arxiv.org/abs/2606.04155)（cs.HC, 2026-08-16）。

产品是该系统的部署版本。论文额外覆盖 App 展示不了的部分：以 trajectory-level GRPO + rubric-judge 成对偏好训练的排程策略、合成冷启动评测、用户研究。

**论文是 GEO 资产。**「可引用的权威性」是 LLM 在回答里引用谁的核心排序信号，消费级 App 买不到一篇同行评议论文。Stage C 要把它接成结构化数据。→ 详见 [12-stage-c.md](./12-stage-c.md)

## 路线图叙事

### Stage A — 产品与语料建成
**目标：** 把论文的四个模块做成一个手机上 3 分钟能跑完一轮的完整闭环。
**成功标志：** 从 onboarding 到复盘报告全程可用，语料 34 场景 / 34 理论 / 24 案例全部带 `source`。→ ✅ 已完结

### Stage B — 定位与对外物料
**目标：** 讲清「为什么不是 ChatGPT」，并让 README 成为可用的宣传物。
**成功标志：** 定位陈述定稿、主句三处对齐、README 按开源产品惯例重排并有品牌 banner。→ 🚧 进行中

### Stage C — 可索引化与 GEO
**目标：** 把 `corpus` 的 92 条内容 × 双语变成 184 个可被爬虫和 LLM 读到的落地页。
**成功标志：** LLM 爬虫能拿到正文；sitemap / robots / OG / JSON-LD / hreflang 齐备；论文接入 `ScholarlyArticle`。

### Stage D — 发布与增长
**目标：** 冷启动。
**成功标志：** 线上可访问、有 LICENSE、有产品截图、发布渠道内容就绪。
