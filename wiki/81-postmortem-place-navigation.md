# 新 3D 空间的导航与动作复盘

饭桌之外连续出现四种相关问题：新空间被旧圆桌障碍阻挡、返回时站立人物会被坐下、远程按钮直接开门、关门后轿厢内没有按钮可退出。共同原因是渲染空间已改变，导航 / 姿态 / 操作可达性仍沿用饭桌假设。

`spaces.ts` 统一人物原始位置、姿态、椅子与障碍；渲染、导航、档案校验使用同一个空间。门动画状态控制实际通行，门口有人则重新打开；内外按钮各有可到达位置。按钮通过走近再按的指令执行，手动移动或取消撤销指令；刷新只恢复门状态，不继续过期指令。

验收不仅比较静态布局，还在路径每个采样点检查家具碰撞，确认抵达白板 / 各人物，完整完成开门 → 进轿厢 → 关门 → 内侧开门 → 返回。站立 NPC 只转向，不随玩家换位。旧 v1 饭桌档案与原导航保持回归测试。

教训：新空间必须一起定义渲染、可通行区域、初始姿态与双向退出路径；不能以看到按钮或找到路径终点作为动作可玩的证明。详见[体验验收](./reviews/review-2026-10-03-3d-places.md)。
