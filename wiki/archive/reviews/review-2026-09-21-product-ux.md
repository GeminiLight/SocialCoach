# 核心练习路径 UI/UX 精修验收

**结论：PASS（本地核心路径范围）。** 没有遗留的 blocker / critical 设计问题。已完成实现、浏览器回归与正式构建；未提交或部署。实体手机软键盘、读屏全流程和线上嵌入环境仍属于后续发布验收，不能把本结论当作全产品 WCAG 认证。

## 范围与依据

受众：希望排练现实对话的中文 / 英文用户。核心任务：选一场适合的练习 → 理解情境 → 开口 → 得到基于原话的复盘 → 下次继续。

保持暖纸色、赭石主动作、原话标注和桌面边注；保留本次工作前已存在的通用练习策略改动，不改场景语料，不新增服务端练习存储。参考已有 `/rehearse` 草稿、`Sheet` 原生弹窗和 `/learn` 阅读分栏的应用内约定。

依据：

- [Nielsen 可用性原则](https://www.nngroup.com/articles/ten-usability-heuristics/)：状态可见、可退出与恢复、减少记忆负担；用于草稿、目录返回、阅读历史及真实等待。
- [W3C 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：WCAG 2.2 AA 的一般下限是 24 CSS px（含间距等例外）。本轮关键触控使用更宽裕的 44px，二者不混称。
- [W3C 焦点不被遮挡](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)：用于复盘锚点、固定底栏与原生弹窗检查。
- 项目 [设计原则](../../03-design-principle.md) 与 `super-product-ux` 八视角 / 十二门禁。

## 验证记录

- `pnpm lint` 与 `pnpm build` 通过（构建包含 TypeScript 检查）。
- 新增 `app/scripts/check-product-ux.ts`：仅允许 localhost，使用独立浏览器、虚构档案和模拟模型接口；不复用用户浏览器数据。
- **15 项交互回归**：即时保存 / 刷新恢复 / 场次隔离；发送清草稿但失败保留转录 / 重试恢复；12 条首屏 / 增量展开 / 筛选重置展示数 / 返回保留筛选 / 空结果；流式回复不抢历史阅读 / 回到最新；Escape 返回焦点 / 焦点可见；清空数据只清本应用草稿与返回地址。
- **80 组布局检查**：五页 × 2 语言 × 2 主题 × 4 宽度。正式构建本地运行通过。
- **40 次 axe-core 4.12.1 扫描**：五页 × 2 语言 × 2 主题 × 手机 / 桌面，零自动违规。对渐变和文字批注等 incomplete 项另做视觉及色值检查，不将 incomplete 当作自动通过。
- 人工补测存储被浏览器拒绝：输入仍保留、发送按钮可用、明确显示未保存。
- 封面辅助文字对五组色底：浅色最低 **6.96:1**，深色最低 **7.43:1**；原话批注底色最低 **7.04:1**；OFF 开关与 inset 底色最低 **4.68:1**。使用浏览器解析 OKLCH / light-dark 后的 sRGB 相对亮度计算。
- 局部保留历史报告兼容；首页只有存在原话证据时才显示上次的下一步建议。

复现（先启动本地服务，需要 `agent-browser` 可执行文件）：

```bash
cd app
UX_BASE_URL=http://localhost:3005 npx tsx scripts/check-product-ux.ts
```

可用 `AGENT_BROWSER_BIN` 指定工具路径、`UX_ARTIFACTS` 指定截图与 JSON 报告目录；`UX_SKIP_MATRIX=1` 只跑交互回归。测试截图中的用户、对话和报告均为夹具，不是真实用户记录。

本轮没有宣称模型结果更准确或线上转化率提高；那些需要独立实验。实际手机软键盘 / 读屏与发布后的平台验证已登记在 [backlog](../../85-backlog.md)。
