# 3D 现场：电梯口与办公室

主站 `/3d` 共用模型、语音、历史与本地档案，新增两种空间、四个开局。不复制饭桌布局或单独维护另一套应用。

## fiction

所有人物、公司、资料和冲突为原创虚构，不作为现实中的劳动、隐私或人事规则。

- 电梯口：会后有人追问与 HR 的私下谈话；或要求在原因未核实前承认演示事故责任。方经理要快速得到口径，乔宁交接了演示链接和账号操作说明，完整性与可访问性待核对，程悦不愿卷入传闻。
- 办公室：临近下班临时加上数据核对、排版、最终检查；客户邮件要求主方案和数据摘要；或方案汇报被资深同事打断。何主管关心交付，宁姐关心会议效率，瑞瑞只确认自己的数据和时间。
- 开局之外的个人经历、故障原因、承诺、任务归属只能来自本局原话。走近不等于私密；抬手不等于获得发言权；查看任务单不等于接下任务。

## 空间与动作

电梯口是停层等候区，允许进入停着的轿厢，不模拟行驶或倒计时。门可开合，有碰撞与门口有人时的防夹；三个 NPC 均保持等候位置，不追随玩家。办公室有工作桌、转椅、窗、任务资料及白板，导航避开家具，返回时恢复各自原本坐姿或站姿。两处均支持第一 / 第三人称、自由环顾、跟随发言人和走到旁边。

动作记录只记实际发生的动作，不生成自动同意台词。新空间不允许举酒杯。电梯按钮、资料、白板也提供可用键盘与触屏访问的界面入口。

## 档案与验收

旧 v1 饭局档案继续可读；新增可选空间与门状态。校验人物、空间、站坐位置、话题和事件归属，拒绝跨场景混装。入口切换需用户明确开始新局，不覆盖未完成对话。

验收包括旧饭局回归、导航 / 门防夹 / 暂停 / 返回姿态、档案与接口非法组合、四开局资料隔离、多轮真实模型与浏览器试玩、中英 / 手机 / 键盘检查。界面准确表述当前可玩的停层电梯口与程序建模人物，不宣称电梯行驶或真人写实资产。
