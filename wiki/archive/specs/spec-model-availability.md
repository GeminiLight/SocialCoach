# 模型可用性与接入恢复

部署密钥存在不等于有效；原连接测试生成了内容，无模型部署的强制弹窗还阻止浏览。本次将连接检查、真实失败后的门控与配置恢复统一。

## 边界

- 只认证读取模型列表 / 详情，5 秒总时限、零重试、无推理测试。官方 OpenAI / Anthropic 元数据接口不生成内容；不能由此保证余额或消息生成权限。
- 无密钥、密钥无效、余额 / 共享额度不足、模型不存在、限流、服务故障、网络故障分别处理。不把普通 429 说成没余额。
- 兼容服务不支持元数据或遇到 CORS / 超时，标记尚未确认，仍可明确保存，在实际练习时确认。实际失败会即时暂停相关操作。
- 单用户限流不会禁用其他用户。缓存和服务端错误观察仅在进程内，浏览器自身维护实时状态。
- BYOK 密钥不进服务端、分析事件、练习档案或导出；无个人 → 共享的静默付费回退。新配置不受旧请求的迟到错误影响。
- 报告 / 引文 / 结构校验失败属于任务错误，保留正常重试能力，不宣称密钥无效。
- AI 依赖的生成、发送、提示和自动分析统一门控，计时练习暂停。浏览场景 / 知识、查看记录、导出、3D 世界探索不受阻。
- 配置默认展示服务商、API Key、模型名称；其他字段折叠。密钥输入可连续编辑，草稿不立即写设置，取消时检查中止。提供服务商官网入口。所有文案双语、沿用现有色彩。

## 验收

- `app/scripts/check-model-availability.ts`：19 组无付费调用检查，覆盖元数据 GET、认证 / 额度 / 限流、兼容服务 / 别名、流式错误、旧配置隔离、取消和并发失败保护。
- `app/scripts/check-model-availability-browser.ts`：23 项本地隔离浏览器检查、模拟共享 API 与服务商；确认无强制弹窗、历史 / 熟练度不变、关键按钮门控、密钥输入 / 不保存无效配置、无生成的连接检查、未确认服务的保存、流式额度失败、计时暂停、免费恢复、中英明暗视口与可访问性。
- 既有复盘助手 23 项任务 / 38 项 UI、12 项中断恢复、19 项练习策略和 98 项 3D 检查通过；TypeScript、变更文件 ESLint、正式构建。
- 浏览器验收仅代表 Chromium 模拟视口，不替代实体手机读屏和真实输入法检查。本轮不做付费模型测试。
