# 3D 与文字练习共用复盘

<!-- Last verified: 2026-10-03 -->

用户在主站 `/3d` 主动结束本段时，将真实转录转换为已有 Session，进入原有复盘、知识、反思与复盘助手。报告留在设备上的主站练习历史；原场景存档与草稿仍可返回。没有发言不能生成评价；到回合边界可续聊，不自动提交复盘。

只新增公开的现场观察与报告补充字段，不新增评价模型或评分口径。NPC 开场、回复、旁人插话与旧已听台词保留顺序；动作不伪装为用户发言，镜头模式、动画情绪、未采纳语音、未发草稿与 NPC 私有设定不做评分证据。现场补充必须引用用户原话并关联同一发言的观察 ID；举杯不等于喝酒或承诺，走近不等于私聊，站起不等于逃避。

验收：五场景 / 十开局转换，旧存档，连续对话后的报告缓存失效，访客无需建档即可复盘，主站历史与导出可查，返回 / 重练路径，引用和观察关联校验，文字报告兼容，取消 / 失败 / 重试不重复加分，中英真实模型、桌面和手机浏览器。

完成实现：`review.ts` 适配现有 Session；`scene-context.ts` 校验公开观察；共用 `/api/assess`、知识、反思、复盘咨询和本地历史。v1 存档仅加可选报告链接与同局 ID，不迁移旧转录。访客 fallback 在 selector 外取值，避免 Zustand 把每次新建的空数组视为快照变化导致报告渲染循环。连续交谈另存新的报告，早结束后的续聊不扩充未到边界的预算。

154 项 3D 检查、23 项原复盘助手合同检查及生产构建通过。真实模型在中英家庭 / 办公室小样本验证引用、评分、公开观察与咨询；补充规则区分未回答的下一回合、限定原句之前的信息和用户原有承诺。具体浏览器流程、剩余语义限制与发布见 [验收](../../reviews/review-2026-10-03-3d-debrief.md)。

同局连续复盘的能力增量去重：必须引用自上次已评价快照以来的新发言，再扣除该技能本局已计入的增量；未新增发言、只改动作 / 位置的快照不再加分。重练新局独立计入。单元检查覆盖三次快照、旧原话、跨新局、旧版兼容与输入 / 旧报告不被修改。
