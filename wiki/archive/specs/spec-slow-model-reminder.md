# 默认模型等待提醒

状态：双平台已发布并验证（2026-10-08）。[验收与发布记录](../../../docs/reviews/slow-model-reminder-2026-10-08/README.md)。

用户希望默认 API 较慢或出现故障时，能直接设置自己的模型。此前场景准备、排练、复盘分别要等待 25、40、60 秒才出现入口，普通对话和 3D 没有同一提示。

默认请求等待约 8 秒后，在当前处理区域显示「等待有点久。自己的模型服务可能更快。」与「接入自己的模型」，中英文一致。按钮打开现有配置窗；当前请求和原处境保留，新设置用于后续请求。已启用个人模型、模型明确不可用或没有待完成请求时，不显示此推荐。真实模型故障沿用现有错误提示及接入恢复；计时器不把慢请求判为故障。

覆盖排程、场景准备、排练、文字对话与提示、复盘生成与反思、复盘咨询、成长模式和 3D 对话。3D 使用当前现场语言和对话面板颜色。按钮明确为普通按钮，避免在表单内触发重发；计时器随等待视图卸载或配置版本变化清理。

浏览器验证先复现原 40 秒门槛，再确认约 8 秒时只有一条提示。配置窗打开不导航、不重发请求、原处境保留，完成后提示消失。手机文字与 3D 提示保持在视口内，英文深色布局无横向溢出；提醒局部可访问性检查无违规。模拟慢响应仅用于体验验证，不作为模型速度证据。未更改模型参数、推理逻辑、密钥、预算或存储。
