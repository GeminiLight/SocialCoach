## 范围与体验

首版只开放唐悦「就改一下，五分钟的事」公共文字场景。准备页、复盘与短练完成页可以邀请；先预览公共开场，再复制邀请 / 保存 PNG / 调用系统分享。固定 v1 场景快照包含原 source，邀请不读取原对话、适配资料、评分、私人场景或本地场次 ID。

接收页 `/challenge/office-quick-favor/v1/{zh|en}` 展示开场、角色、目标、公共背景；不经过填写档案。明确点击开始才建立自己的本地练习，复用欢迎页已有的空白访客档案和现有对练 / 复盘流程，不生成个人适配。相同版本和开场，后续回应随行动生成，不能称为同难度竞技或朋友成绩比较。

主站链接直接使用已发布主站；国内链接使用 ModelScope 公开包装页的 `app_path` 参数。不经会丢路径的统一域名。预览可选择接收入口，二维码与复制文本使用同一个实际 URL；未知题目 / 版本明确失效并可选择现有题，不静默换题。

## 边界

- 卡片纯本地绘制，无模型调用、远程二维码服务、账号或服务端练习存储。不新增转发/朋友关联或邀请统计，已有练习事件仍按原开关发送。
- PNG / 链接仅含受控题目、版本、语言和部署选择；不能附加私人文字、任意 URL 或追踪 ID。分享菜单打开、复制、保存均不冒充实际发送。
- 图片失败保留链接；剪贴板被拒保留可选文本；原生分享取消无错误 / 自动外发；不支持时给出保存 / 复制操作。
- 原有未完成练习保留；重复点击不创建双份；同题未完成记录可续接。旧档兼容，新增版本标记随导出恢复。
- 用户资料、未公开研究、密钥不进入产品记录或发布包。

## 验收

纯逻辑覆盖固定版本、独立档案、不包含私有资料、非法链接、二维码解码、存档兼容。浏览器检查发送方 → 复制/图片二维码 → 干净接收设备 → 首句 → 复盘；中英 × 明暗 × 手机/桌面，刷新/返回/已有练习/重复操作/存储失败/取消和降级。公开双站验证真实链接与国内 iframe 路径；正式构建、相关回归和质量检查通过后发布。真实微信/手机分享面板、真实朋友完成率另记，不用自动化代理。
